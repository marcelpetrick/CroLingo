# LinkedIn pipeline image set

These five AI-assisted landscape illustrations support a post about CroLingo's
local, GitHub, and release automation. They are social-media concepts, not
runtime application assets. Each JPEG is 1731 x 909 pixels, has its metadata
removed, and uses quality 91 to balance feed clarity and repository size.

## Images

| File | Visual direction | Best use |
| --- | --- | --- |
| `01-quality-metrics.jpg` | Clean editorial metrics infographic | Data-led opening image |

| `03-regression-shield.jpg` | Paper-cut crow defending against regressions | Automation-value story |

| `05-release-control.jpg` | Cinematic Adriatic release control room | Emotional hero or closing image |

## Generation briefs

The built-in image generator received one prompt per image:

1. A Swiss-editorial CroLingo infographic with the exact metrics `129 TESTS`,
   `98.23% COVERAGE`, `20 CHECKS`, and `6 RELEASE PACKAGES`.
2. A tactile isometric factory whose conveyor moves Croatian/German learning
   cards through `LOCAL`, `GITHUB`, and `RELEASE` stations.
3. A layered paper-cut scene in which an original crow and checkmark shield
   protect learning data from friendly regression bugs, headed `AUTOMATION
   STOPS REGRESSIONS`.
4. A geometric transit map joining Croatian, German, and software-quality lines
   from `LOCAL` through `GITHUB CHECKS` to `VERIFIED RELEASE`, with the current
   test, coverage, and stage figures.
5. A cinematic Adriatic release-control room featuring the crow, paired
   Croatian/German vocabulary, six packages, and the headline `FROM COMMIT TO
   CONFIDENCE`.

All prompts required an original family-friendly black crow, restrained
Croatian red-white-blue and German black-red-gold cues, a wide LinkedIn layout,
and no imitation of an existing language-learning brand. The generated PNGs
were visually inspected, converted to sRGB JPEG, and stripped of metadata.

Figures represent the repository snapshot documented in
[`docs/pipeline_support.md`](../../docs/pipeline_support.md). Regenerate or edit
the copy if those figures change materially before publication.
