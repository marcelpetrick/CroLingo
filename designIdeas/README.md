# CroLingo visual design ideas

These ten AI-assisted concept illustrations explore an original, friendly crow
for success, encouragement, recall, and learning-progress moments. They are
design references, not bundled runtime assets. A selected direction must be
redrawn or deliberately approved, accessibility-reviewed, optimized, and added
to `pubspec.yaml` before it can appear in the application.

## Generation brief

The built-in image generator received one distinct prompt per illustration.
All prompts shared this base brief:

> Create a square CroLingo design concept using an original, friendly
> charcoal-gray crow with rounded geometry. Use a polished family-friendly 2D
> children's editorial style, Adriatic blue, warm cream, Croatian red, and
> restrained black-red-gold cultural accents. Croatian and German flag cues
> must be accurate and respectful. Include no text, watermark, logo, copied app
> interface, or recognizable existing mascot.

The ten scene prompts requested, in order: a jumping lesson celebration, a
flashcard bridge, a shared Croatian–German heart, a paper-airplane learning
journey, a family medal celebration, interlocking recall puzzle pieces, a
growing vocabulary tree, a lighthouse learning beacon, a ribbon victory dance,
and a conversation picnic.

The generated PNG sources were visually inspected, resized to 1024×1024,
metadata-stripped, and stored as quality-88 WebP files to keep repository size
reasonable. No generated image is included in Android or Linux builds.
